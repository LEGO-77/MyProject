## Инструкции для работы с функциями
### Модуль masks
#### Функция get_mask_card_number
Принимает номер карты и возвращает ее маску в формате XXXX XX** **** XXXX\
Пример:\
print(mask_account_card("Visa Platinum 7000792289606361"))\
Вернет строку вида: 7000 79** **** 6361

#### Функция get_mask_account
Принимает номер аккаунта и возвращает его маску в формате ****************XXXX\
Пример:\
print(mask_account_card("Счет 73654108430135874305"))\
Вернет строку вида: ****************4305

### Модуль processing
#### Функция filter_by_state
Принимает список словарей и параметр key (по умолчанию = EXECUTED), возвращает новый список, в котором только словари, где ключ state равен входному параметру key\
Пример:\
print(
    filter_by_state(
        [
            {"id": 41428829, "state": "EXECUTED", "date": "2019-07-03T18:35:29.512364"},
            {"id": 939719570, "state": "EXECUTED", "date": "2018-06-30T02:08:58.425572"},
        ],
        "CANCELED",
    )
)\
Вернет строку вида:\
[
    {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
    {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}
]

#### Функция sort_by_date
Принимает список словарей и параметр sort_desc, сортирует по ключу date в зависимости от входного параметра sort_desc\
Пример:\
print(
    sort_by_date(
        [
            {"id": 41428829, "state": "EXECUTED", "date": "2019-07-03T18:35:29.512364"},
            {"id": 939719570, "state": "EXECUTED", "date": "2018-06-30T02:08:58.425572"},
            {"id": 594226727, "state": "CANCELED", "date": "2018-09-12T21:27:25.241689"},
            {"id": 615064591, "state": "CANCELED", "date": "2018-10-14T08:21:33.419441"},
        ]
    )
)\
Вернет список вида:\
[
    {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
    {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'},
    {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
    {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}
]
